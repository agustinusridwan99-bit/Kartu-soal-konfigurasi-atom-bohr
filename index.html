⚛️ Konfigurasi Elektron Bohr Kulit K, L, M, N dan aturan pengisiannya

📖 Model Atom Bohr: Kulit Elektron

Menurut Teori Atom Bohr, elektron berada dalam lintasan (orbit) tertentu yang disebut kulit elektron, diberi lambang KLMN dihitung dari inti atom.

Rumus jumlah elektron maksimum per kulit:
Σ maksimum = 2n²
Nomor Kulit (n)LambangElektron Maks (2n²)
1K2
2L8
3M18
4N32

Contoh: kulit ke-3 (M) → 2×3² = 18 elektron.

🔹 Aturan Pengisian Kulit K dan L

  • K Diisi 2 elektron jika tersedia ≥ 2. Khusus Hidrogen (H) diisi 1 elektron.
  • L Diisi 8 elektron jika tersedia ≥ 8. Jika tersedia < 8, diisi sisa elektron.
₃Li : 2, 1 → K=2, L=1
₁₂Mg : 2, 8, 2 → K=2, L=8, M=2

🔸 Aturan Pengisian Kulit M dan N

  • M 18 e⁻ jika tersedia > 18; 8 e⁻ jika 8 ≤ e⁻ < 18; sisa jika e⁻ < 8.
  • N 32 e⁻ jika tersedia > 32; 18 e⁻ jika 18 ≤ e⁻ < 32; 8 e⁻ jika 8 ≤ e⁻ < 18; sisa jika < 8.
₂₀Ca : 2, 8, 8, 2
₁₇Cl : 2, 8, 7
₃₆Kr : 2, 8, 18, 8
₃₈Sr : 2, 8, 18, 8, 2

⚡ Konfigurasi Ion

  • Ion positif (kation) → atom melepas elektron. Contoh: Na⁺ (11−1 = 10 e⁻) → 2, 8.
  • Ion negatif (anion) → atom menangkap elektron. Contoh: Cl⁻ (17+1 = 18 e⁻) → 2, 8, 8.

📋 Petunjuk Bermain

1. Pilih atom atau ion yang ingin kamu tantang dengan menekan tombol unsur di panel Soal.
2. Tentukan konfigurasi elektron berdasarkan aturan Bohr (K, L, M, N).
3. Untuk ion: hitung dulu jumlah elektronnya (kation = nomor atom − muatan, anion = nomor atom + muatan).
4. Tulis jawabanmu dengan format: 2, 8, 1 (angka dipisahkan koma dan spasi).
5. Tekan tombol Periksa Jawaban untuk melihat feedback.
6. Jika benar, kamu bisa memilih atom/ion lain. Jika salah, coba lagi!

💡 Contoh: Na → 2, 8, 1. Na⁺ → 2, 8. Cl⁻ → 2, 8, 8.
